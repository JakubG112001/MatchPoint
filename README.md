
 MatchPoint

MatchPoint is a serverless dating application built on AWS that allows users to sign up, create profiles, swipe to like or dislike other users, and chat with mutual matches. The app demonstrates full cloud architecture using:

- Frontend: React hosted on S3 with CloudFront
- Authentication: AWS Cognito
- API & Business Logic: AWS Lambda + API Gateway
- Database: DynamoDB (NoSQL)
- Media Storage: Amazon S3 (profile pictures)

This project showcases cloud-native design, cost-efficient serverless architecture, secure authentication, and scalable data modeling — ideal for junior cloud roles and AWS certification portfolios.
